# UI Mockups

当前基线：

- `personal-ai-workspace-ui.html`：可交互的多页面 UI 风格稿；
- `personal-ai-workspace-ui.png`：全宽桌面布局静态预览；
- `screenshots/today-page.png`：Today 页面；
- `screenshots/inbox-page.png`：统一收件箱页面；
- `screenshots/calendar-page.png`：日历页面；
- `screenshots/tasks-page.png`：任务页面；
- `screenshots/notes-page.png`：笔记页面；
- `screenshots/ai-command-page.png`：AI Command 页面。

HTML 文件用于体验导航、页面布局和 AI 上下文面板；PNG 文件用于快速查看和设计评审。实际产品实现不直接依赖这些文件，后续将按同一设计规范迁移到 Next.js 组件。
