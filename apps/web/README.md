# Web 应用

个人 AI 工作台的 Next.js Web 客户端。目前包含 Today、Inbox、Calendar、Tasks、Notes、AI Command 和账户设置七个路由，以及共用的导航、命令栏和 AI 上下文面板。账户设置入口位于左下角用户名菜单，设置页按邮件、日历和预留的 ToDo 标签组织。

账户设置页采用“先测试、后保存”流程：只有只读连接测试成功后才会启用保存按钮。IMAP/SMTP 会执行真实的 IMAP 登录、文件夹读取和 SMTP 握手验证；测试不会发送邮件。保存时会再次验证连接、加密凭据、建立账户记录，并同步首批邮件摘要到统一收件箱。Microsoft Graph 和 Gmail API 将在后续连接器中启用。

已保存账户会显示在添加表单下方，包括账户名称、邮箱地址、健康状态、同步范围和上次成功同步时间。可以手动同步、暂停/启用、重新配置或删除账户。重新配置接口只返回服务器地址、端口和用户名，绝不会把已保存密码返回浏览器；修改后必须重新输入密码并通过连接测试。

本机服务会在首次打开账户设置或 Inbox 后启动后台同步，默认每 3 分钟按 IMAP UID 检查新增邮件，并继续分批回填历史摘要。失败账户独立退避，不会阻塞其他账户。可通过 `KALENDER_SYNC_INTERVAL_MS` 调整间隔，最小为 30 秒。

每轮同步还会检查各文件夹最近 200 个 UID，更新已读和星标状态；如果窗口内某个 UID 已从远端消失，本地索引也会移除，以反映邮件移动或删除。该过程只读远端状态，不会主动修改邮箱。

Inbox 只同步邮件摘要。打开真实邮件时才会通过 IMAP 读取完整 MIME，解析纯文本和 HTML，并在服务端移除脚本、表单、远程图片、事件属性和危险链接。清洗后的正文会写入本地缓存，再次打开不会重复下载；默认 30 天过期、总容量限制为 128 MB，后台任务每 6 小时清理过期和超限内容。界面提供加载状态、失败提示与重试按钮。

邮件列表使用共享 `ContextMenu` 和命令注册表。右键、每行的三点按钮、键盘菜单键及 `Shift + F10` 打开同一组命令，关闭后焦点返回原对象；`Shift + 右键` 保留浏览器原生菜单。真实账户可以直接标记已读/未读、添加/取消星标，并在二次确认后归档；这些操作先提交远端 IMAP，成功后才更新本地索引。“创建任务”和“AI 总结”会在对应模块接通前明确显示为不可用。

Calendar 已接入本地 `CalendarProvider`、CalDAV 只读 Provider 和持久化事件库。正式周视图包含 07:00–22:00 小时轴、全天区域、按 15 分钟定位和重叠事件排列；月视图使用完整六周网格，支持跨日事件和“更多日程”展开。顶部可以切换周/月视图、返回今天或前后导航，最后选择会保存在浏览器中。

账户设置页可添加多个 CalDAV 账户：必须先通过只读连接测试，随后才会加密保存凭据并同步过去 180 天至未来一年的事件。日历发现、ICS 时区/全天/参与者/会议链接解析和服务器重复实例展开已经接通；不同日历使用各自颜色显示。远端日历目前明确标记为只读，保存时同步和手动同步不会修改服务器数据。双向写入、后台定时同步和 sync-token 增量同步将在下一阶段实现。

日历设置还支持 HTTPS 或 `webcal://` ICS 链接订阅。链接必须先通过内容与连接安全测试；完整订阅地址会作为敏感凭据加密保存，账户列表只显示脱敏地址。保存后可手动重新同步，事件始终只读，任何本地操作都不会写回发布日历。

## 本地运行

在项目根目录执行：

```powershell
npm install
npm run dev
```

然后访问 `http://localhost:3000/today`。

## 本地数据与密钥

- 开发版使用 PGlite 将 PostgreSQL 数据写入项目根目录的 `.data/postgres`；
- Schema 使用事务化版本迁移；升级旧数据库前自动创建 PGlite 恢复快照，可用 `npm run db:migrations:status` 检查状态；
- 邮箱密码使用 AES-256-GCM 加密，首次保存账户时会生成 `.data/master.key`；
- `.data` 已加入 `.gitignore`，不得提交到版本库；
- 备份邮箱账户时必须同时安全备份数据库和 `master.key`，丢失密钥后无法解密已保存凭据；
- 部署时建议通过 `KALENDER_MASTER_KEY` 提供 32 字节 Base64 密钥，并将数据层切换为托管 PostgreSQL。

首次保存可选择最近 30 天、最近 90 天或完整历史范围。当前请求内先同步至多 100 封邮件摘要，避免大邮箱让保存操作长时间阻塞；后续后台任务将继续回填。

## 工程检查

```powershell
npm run typecheck
npm test
npm run build:web
```

如果尚未保存真实账户，Inbox 会保留演示数据；保存账户后则只显示数据库中的真实同步结果。附件当前只保存元数据，文件内容将在后续实现按需安全下载。
